# Contribuer / Contributing

**Objectif : documentation vérifiable et réutilisable, pas promesse universelle.**

Pour chaque proposition, décrire : référence modèle et SoC (si connu), firmware, version go2rtc/FFmpeg, symptômes, étapes, mesures, résultat **réellement testé** et limites.

Statuts obligatoires :
- **Validé / Tested** : résultat observé sur matériel identifié.
- **Partiel / Partial** : service présent sans preuve de vidéo/événement complet.
- **À tester / Planned** : hypothèse ou travail futur.

Ne **jamais** publier d'URL Tuya réelle, e-mail, mot de passe, device ID, jeton, IP privée réelle de l'installation, image domestique, log DEBUG brut, dump MTD ou firmware. Ne pas redistribuer le code d'un projet tiers sans respecter ses conditions de licence.

Toute nouvelle fonction Home Assistant et Frigate Glance doit être présentée **expérimentale** avant une validation bout en bout. Préserver le firmware stock et les réglages du lanceur CleanYourTV existant.
